# Mars Radiation Tower

Play a junior radiation operator in a fictional Martian outpost. Learn the tower tools during a supervised practice, then track local radiation and advise an inspection crew during a simulated solar particle event.

## Open the game

Open `index.html` in a modern browser. Use WASD or the arrow keys to move and E to interact. Use the on-screen movement and interaction controls on touch screens. The Phone station connects you to the instructor.

## Publish on GitHub Pages

1. Copy the contents of this folder into the root of your GitHub repository and commit them.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select your branch (usually `main`) and **/ (root)**, then save.

The game uses static files. It requires no build, API key, or server-side code. See [GitHub's publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Science and art

- The shift is inspired by the solar particle event observed on Mars on May 20, 2024. The mission timeline, simulated radiation rates, crew readings, and outpost layout are training values. [NASA/JPL event report](https://www.jpl.nasa.gov/news/nasa-watches-mars-light-up-during-epic-solar-storm/)
- DONKI is a NASA space-weather event catalog, and RAD is the Radiation Assessment Detector aboard Curiosity. [NASA DONKI](https://ccmc.gsfc.nasa.gov/tools/DONKI/) · [Curiosity RAD](https://www.jpl.nasa.gov/images/pia13580-radiation-assessment-detector-for-mars-science-laboratory/)
- The magnetic field activity illustrates how a magnetic field can bend charged particles. Active shielding for human missions is a research concept. [NASA on radiation shielding](https://science.nasa.gov/resource/real-martians-how-to-protect-astronauts-from-space-radiation-on-mars/)
- The tower and character artwork are adapted from the supplied reference image.
