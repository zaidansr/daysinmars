# Art sources

The environment uses the CC0 Space Kit by Kenney, supplied with its original license in the downloaded pack.
Source https://opengameart.org/content/space-kit and https://kenney.nl/assets/space-kit

The operator walk cycle and instructor use the CC0 Space Guy sprite sheet by patvanmackelberg.
Source https://opengameart.org/content/space-guy-8-directional-animated-character-16x16

The source images were cropped, resized, palette-mapped and assembled using Codixel's pixel.js core.
Codixel https://github.com/mankidev/codixel, MIT license.

tower-floor.png is a 224 × 210 composition. Console prop textures are 20 × 20 pixels.
operator-walk.png contains three frames for each of the four cardinal directions, using the source artist's walking frames. It is 48 × 64 pixels.
instructor.png is a recolored 16 × 16 source character.
All scene art comes from the sources above. Radar lines, labels and interface shapes are functional browser UI.
